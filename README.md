# BobMess

**BobMess** — мой личный проект мессенджера, который я развиваю как полноценный продукт для общения людей.

Сейчас BobMess находится на стадии активного frontend-прототипа. В проекте уже реализованы авторизация, серверы, каналы, личные сообщения, друзья, заявки, блокировки, уведомления, вложения, настройки, мобильная адаптация и PWA-режим.

Главная цель проекта — постепенно превратить BobMess в настоящий работающий мессенджер с backend, базой данных, realtime-сообщениями, уведомлениями, звонками и возможностью пользоваться приложением на разных устройствах.

---

## Цель проекта

Я хочу сделать не просто интерфейс, а полноценный мессенджер, которым смогут пользоваться люди.

BobMess должен развиваться в сторону настоящего продукта:

* общение в личных сообщениях;
* общение на серверах и в каналах;
* друзья и заявки;
* роли и права;
* уведомления;
* изображения и вложения;
* мобильная версия;
* установка как приложение;
* backend API;
* база данных;
* realtime через WebSocket;
* голосовые и видеозвонки через WebRTC;
* синхронизация между устройствами;
* публикация для реальных пользователей.

---

## Текущий статус

На данный момент BobMess работает как **frontend-only приложение**.

Данные хранятся в `localStorage`, поэтому текущая версия работает локально в браузере. Это временный этап, который нужен для разработки интерфейса, логики и общей структуры приложения.

Сейчас данные доступны только:

* в одном браузере;
* на одном устройстве;
* без настоящего сервера;
* без общей базы данных;
* без синхронизации между пользователями.

В будущем localStorage должен быть заменён на полноценный backend с базой данных и realtime-соединением.

## PWA

BobMess уже подготовлен как PWA-приложение.

Это значит, что приложение можно установить на телефон или компьютер, если открыть проект через локальный сервер или опубликованный HTTPS-адрес.

Для локального запуска:

```bash
python -m http.server 5500
```

После запуска открыть:

```txt
http://localhost:5500
```

На Android приложение можно установить через меню браузера:

```txt
Добавить на главный экран / Установить приложение
```

На iPhone через Safari:

```txt
Поделиться → На экран “Домой”
```

На ПК в Chrome или Edge может появиться кнопка установки приложения в адресной строке.

## Ограничения текущей версии

Сейчас BobMess ещё не является полноценным online-мессенджером.

Текущие ограничения:

* нет настоящего backend;
* нет общей базы данных;
* пользователи не синхронизируются между устройствами;
* сообщения не приходят в реальном времени между разными браузерами;
* звонки пока не реализованы;
* файлы и изображения хранятся локально;
* авторизация пока локальная;
* безопасность пока прототипная;
* localStorage не подходит для реального многопользовательского приложения.

Эти ограничения будут закрываться при переходе на backend.
