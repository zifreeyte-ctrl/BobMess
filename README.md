# BobMess

**BobMess** — это учебный frontend-проект мессенджера, который создаётся на чистых технологиях: **HTML, CSS и JavaScript**.

Проект вдохновлён идеей современных коммуникационных платформ, но развивается как самостоятельный продукт со своим стилем, архитектурой и логикой. Главная цель BobMess — не просто сделать красивый интерфейс, а постепенно построить масштабируемое приложение с ООП, компонентной структурой и возможностью дальнейшего подключения backend.

## Цель проекта

Цель BobMess — создать полноценный браузерный мессенджер, который можно постепенно развивать от локального frontend-прототипа до настоящего онлайн-приложения.

Проект помогает изучать:

* объектно-ориентированное программирование в JavaScript;
* работу с ES6-модулями;
* архитектуру frontend-приложений;
* компонентный подход без фреймворков;
* работу с localStorage;
* проектирование UI;
* структуру больших JavaScript-проектов;
* подготовку проекта к публикации на GitHub Pages.

## Технологии

Проект использует:

* HTML5
* CSS3
* JavaScript ES6+
* ES Modules
* LocalStorage
* GitHub Pages

Без фреймворков, сборщиков и backend на текущем этапе.

## Возможности сейчас

На данный момент в BobMess уже реализованы:

* регистрация и вход пользователя;
* локальная база данных через localStorage;
* создание серверов;
* приватные серверы;
* вход на сервер по invite-коду;
* создание каналов;
* владелец канала;
* редактирование и удаление своих сообщений;
* личные сообщения;
* список друзей;
* добавление друзей по нику;
* поиск сообщений;
* переключение темы;
* профиль пользователя;
* смена ника, аватара и статуса;
* роли и базовые права доступа;
* компактный интерфейс сообщений;
* контекстное меню по правой кнопке мыши;
* адаптация проекта под GitHub Pages.

## Статус проекта

Проект находится в активной разработке.

Сейчас BobMess — это frontend-приложение, которое работает локально в браузере. Все данные сохраняются в `localStorage`, поэтому они доступны только на конкретном устройстве и в конкретном браузере.

Это осознанный этап разработки. Архитектура проекта строится так, чтобы в будущем можно было заменить localStorage на настоящий backend.

## Запуск проекта локально

Проект можно запустить через Live Server в VS Code.

1. Открыть папку проекта в VS Code.
2. Установить расширение **Live Server**.
3. Открыть `index.html`.
4. Нажать правой кнопкой мыши.
5. Выбрать **Open with Live Server**.

После этого проект откроется в браузере.

## Публикация на GitHub Pages

Проект можно опубликовать через GitHub Pages.

После загрузки файлов в репозиторий нужно открыть:

```txt
Settings → Pages
```

Затем выбрать:

```txt
Source: Deploy from a branch
Branch: main
Folder: /root
```

После сохранения сайт будет доступен по адресу:

```txt
https://zifreeyte-ctrl.github.io/BobMess/
```
